The idea is to use an agent to improve itself by trying different ideas. The agent is given a instructions to keep iterating on ideas to improve its diagramming skill. We provide an initial version of the sketch skill and then ask the agent to install the skill and improve it. After the iterative tuning, the skill can be used to sketch any diagram given an rough sketch. With just 10 ietrations, we were able to get a decent looking image.
